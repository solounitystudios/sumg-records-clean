# Prompt Cheatsheet — NightWire

Quick reference for generating NightWire thumbnails in Midjourney or DALL-E.

---

## Copy-Paste Starter

```
young Black creative in [LOCATION], [CAMERA STYLE], [MOOD], Black culture energy, cinematic realism, high CTR YouTube thumbnail, mobile optimized --ar 16:9
```
