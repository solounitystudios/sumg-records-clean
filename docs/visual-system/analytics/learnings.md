## Purpose

This file captures non-obvious learnings about what drives CTR for SUMG producers. Not data points — insights.

---

## How to Write a Learning

A learning is: **[observation] because [reason] → [implication for future thumbnails]**

Example:
> "Museum Nights thumbnails outperform Street Prestige thumbnails on Monday-Wednesday. Likely because commute hours reward curious/intellectual imagery over party energy. → Batch Museum Nights styles for Mon-Wed uploads."
